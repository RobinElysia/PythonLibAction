## 激活函数

### sigmoid函数
1. sigmoid函数数学性质比较阶跃函数好，可导连续，可以表示概率值（全为正数）
2. 但是它的实际有效值数值域范围有限（在[-6,6]），输入值过小或过大会无法计算或者直接数值消失，导致无法计算
3. 可能影响梯度计算，导致梯度消失

### tanh函数
1. Tanh 函数和Sigmoid函数相似，都是非线性函数，但是Tanh函数的输出范围更广，[-1, 1]，Sigmoid函数的输出范围是[0, 1]，
2. 但是x的取值更小，因此Tanh函数更适合处理输入值较小的情况，而Sigmoid函数更适合处理输入值较大的情况（在[-3,3]）。
3. 是由Sigmoid函数乘2减1得到的，双曲正切函数 
4. Tanh函数关于关于x轴对称，但同样有梯度消失 
5. 对应numpy中的 tanh() 函数

### ReLU函数（Rectified Linear Unit，修正线性单元）
1. 为了解决梯度消失问题，我们有了ReLU函数，它可以作用于隐层作为激活函数，也可以作为输出层作为激活函数。
2. 仅有一个不可导点，但是无伤大雅
3. 没有激活就是平的，激活了就是一条直线
4. 当x小于等于0时，ReLU函数输出0，当x大于0时，ReLU函数输出x
5. 它的导函数就是阶跃函数
6. 不存在梯度消失，且当x小于零时，部分神经元是活跃的，可以减少计算量，但是一直为小于等于0的x，会导致神经元死亡问题

### leaky ReLU函数
1. ReLU 激活函数的改进，当x小于0时，输出$\alpha$x，当x大于0时，输出x
2. 避免神经元死亡

### softmax函数：多分类激活函数
1. Softmax函数公式原理：$softmax(x)_i = \frac{e^{x_i}}{\sum_j e^{x_j}}$
   1. 其中$x_i$ 表示第 i 个神经元的输入
   2. $softmax(x)_i$ 表示第 i 个神经元的输出
   3. $e^{x_i}$ 表示第 i 个神经元的指数
   4. $\sum_j e ^{x_j}$ 表示所有神经元的指数之和
2. 它的求偏导为：
   1. 当$j=i$，则求偏导和sigmoid函数类似
   2. 当$j\neq i$，则求偏导为$-f(x_i)f(x_j)$
3. 它的指数会放大较大的值，缩小较小的值，且所有概率之和为1

### Identity 函数(恒等函数)
1. 恒等函数，输出和输入相同，即$f(x)=x$
2. 你是啥就输出啥
3. 输出层会用，导数为1

### PReLU 函数 (Parametric Rectified Linear Unit)
1. 激活函数的改进，当x小于0时，输出$\alpha$x，当x大于0时，输出x
2. 和ReLU函数类似，但是 $\alpha$ 是一个参数，而不是一个超参数
3. $\alpha$不再是超参数，而是一个参数向量，每个神经元对应一个参数，参数向量可以通过训练得到

### RReLU 函数 (Rectified Randomized Linear Unit)
1. 激活函数的改进，当x小于0时，输出$\alpha$x，当x大于0时，输出x
2. $\alpha$是从一个均匀分布 $[0,1]$ 中随机选择的。还是超参数，但是随机

### ELU 函数 (Exponential Linear Unit)
1. 当x小于等于零，输出$\alpha(e^x-1)$，当x大于零时，输出x

### Swish 函数 (Sigmoid-weighted Linear Unit)
1. 激活函数的改进，当x小于0时，输出$\frac{x}{(1+e^{-x})}$，当x大于0时，输出x

### Softplus 函数 (Softplus)
1. 当x小于0时，输出$\ln(1+e^x)$，当x大于0时，输出x
2. 求导后是Sigmoid函数

## 总结
1. 隐藏层首选：ReLU
2. Sigmoid函数会出现梯度消失，尽量少选
3. Than均值为0，对中心数据友好
4. 输出层：二分类Sigmoid、多分类Softmax、回归默认恒等函数
